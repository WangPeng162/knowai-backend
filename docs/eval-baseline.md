# RAG 检索质量基线（Baseline）

> 评估对象：Embedding(text-embedding-v4) + Qdrant 检索链路，不含 Agent/生成层（隔离变量）
> 数据集：eval/dataset.json，20 题，knowledgeId=22（广西农业职业技术大学介绍.pdf，documentId=17，共 19 个 chunk）

## 指标定义

| 指标 | 含义 |
|------|------|
| HitRate@K | Top-K 检索结果中命中该题答案线索的题目占比 |
| MRR | 第一个命中 chunk 排名倒数的平均值 |

判分口径：
- chunk 命中 = chunk 文本包含该题任一 answerKeyword（OR，忽略大小写）
- loose=true（宽松题）：Top-K 拼接文本含任一关键词即命中
- loose=false（严格题，多关键词答案）：Top-K 拼接文本须覆盖全部关键词

## 实验 1：rerank 精排对比（2026-09-08）

**配置**：粗召回 Top-20（embedding，knowledgeId 过滤）→ gte-rerank-v2 打分重排，同一召回池对比两条流水线（EvalRunner.runCompare 一次跑出）

| 指标 | embedding 直排 | embedding + rerank | 提升 |
|------|---------------|-------------------|------|
| HitRate@1 | 45.0%（9/20） | **60.0%（12/20）** | **+15.0%** |
| HitRate@2 | 75.0%（15/20） | **90.0%（18/20）** | **+15.0%** |
| HitRate@5 | 95.0%（19/20） | 95.0%（19/20） | 0（@5 已到上限，Q8 数据缺失救不回） |
| MRR | 0.6742 | **0.7667** | **+0.0925** |

**结论**：
1. **rerank 治排序不治召回**——@5 不变（都能找到），但答案被系统性"顶到前面"（@1/@2 各 +15%）。线上 Agent 只看 Top-2 → **线上命中率 75% → 90%**，这是实打实的体验提升
2. **排名提前 6 题**：Q3(4→2)、Q7(2→1)、Q11(5→2)、Q12(5→2)、Q18(3→1)、Q20(2→1)——正是基线里"答案排太靠后"的那批弱命中题（年份类、长关键词类）
3. **轻微退化 2 题**：Q10(1→2)、Q2(2→3)——rerank 并非完美，未来可做 embedding 分数与 rerank 分数的 hybrid 融合排序
4. 工程落地：rerank API 失败时降级回 embedding 排序（KnowledgeSearchTools 已加 try-catch + 分数数量防御）

## 实验 2：切分器升级对比（2026-09-08）

**配置**：手写 800 字符硬切（句子腰斩，如"师578人"）→ LangChain4j `DocumentSplitters.recursive(800, 100)`（段落→句子→词→字符递归找语义边界）。doc 19 重解析：17 → 16 chunks，全部以完整句/标题开头，无腰斩残留。

| 指标 | 旧切分+rerank | 新切分+rerank | 提升 |
|------|--------------|--------------|------|
| HitRate@1 | 60%（12/20） | **80%（16/20）** | **+20%** |
| HitRate@2 | 90%（18/20） | **95%（19/20）** | +5% |
| MRR | 0.7667 | **0.8750** | +0.108 |

**结论**：
1. **切分质量 = 检索地基**。句子腰斩治好 → 答案完整落单块 → embedding 直排 @1 也从 45→50%（不靠 rerank 也变好）
2. 弱命中题被"双杀"救回：Q11（1942 年溯源）rank5→**rank1**、Q2/Q4/Q12/Q19/Q20 全进 rank1——年份题腰斩治好 + rerank 双重效果
3. **线上 Top-2 命中率从 75% → 95%**，离满分只差原 Q8（数据缺失）

## 实验 3：Q8 数据集修正（2026-09-09）→ 评估全绿

**背景**：原 Q8（在校学生总规模，答案 19002/两万多人）经排查确认——答案只存在于已删除的 doc17（网页版），doc19 正式版全文无全校学生总数。改题"两万多人"后仍 miss，实证"文档治理前须检查评估集依赖"的教训。
**修法**：Q8 替换为"现任党委书记和校长分别是谁？"（关键词 `["文信连","李向红"]`，严格 AND 双事实题），dataset.json 全部 documentId 修正 17→19。

| 指标 | Q8 修正前 | Q8 修正后（全绿） | 
|------|----------|-----------------|
| HitRate@1 | 80%（16/20） | **85%（17/20）** |
| HitRate@2 | 95%（19/20） | **100%（20/20）** 🎉 |
| HitRate@5 | 95% | **100%** |
| MRR | 0.8750 | **0.9250** |

**额外收获**：新 Q8 是"双事实必须同时命中"的题，embedding 直排只排到 rank 7（@5 miss），rerank 拉到 rank1（标记"rerank 救回"）——rerank 价值的新证据。
**注**：v0-v2 轨迹基于旧数据集（含答案源已删的 Q8），与修正后不可严格同比；修正后 @2/@5 封顶 100%。
